# Naga Pro wheel tilt on macOS

The wired Naga Pro wheel-tilt buttons are mapped to macOS Space switching by default:

- tilt left: `Ctrl+Left`
- tilt right: `Ctrl+Right`

The mappings remain editable in the Buttons tab.

If macOS does not switch Spaces, open System Settings → Keyboard → Keyboard Shortcuts → Mission Control and enable Move left a space / Move right a space for Control+Left Arrow and Control+Right Arrow.
